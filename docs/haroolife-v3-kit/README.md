# HarooLife V3 — kit de référence pour Claude Code

Ce pack contient le prompt complet corrigé, 213 modèles GLB Kenney, leurs textures externes, leurs licences CC0 et les aperçus officiels. Ce n’est pas un jeu exécutable ni une carte déjà intégrée à Saas.

## Utilisation

1. Décompresse ce ZIP sur ton PC, par exemple dans un dossier de référence à côté de Louistatch/Saas.
2. Ouvre Claude Code dans ton dépôt Saas.
3. Donne-lui le chemin de PROMPT_HAROOLIFE_V3_COMPLET.md et du dossier assets. Joins séparément tes captures Lagos Life et les captures du résultat refusé.
4. Demande : « Exécute le prompt V3 complet. Utilise les modèles fournis, conserve le Saas et valide le vrai rendu, les mouvements et les interactions. »

Le prompt inclut les corrections du V2 et le nouveau cahier de carte et d’interactions. CARTE_ET_INTERACTIONS_V3.md est un extrait pratique de ce complément.

## Collections

- city-commercial : 41 GLB.
- city-suburban : 40 GLB.
- city-roads : 95 GLB.
- city-industrial : 37 GLB.

Chaque dossier assets/city-* contient ses GLB et son dossier Textures. Ne mélange pas les colormap.png des collections. Chaque collection possède sa licence d’origine.

Les aperçus sont dans previews/, et ASSET_MANIFEST.json contient les sources, empreintes et fichiers vérifiés. Les personnages Quaternius et le mobilier déjà présents dans Saas sont à réutiliser : ils ne sont pas dupliqués dans ce pack.

L’assemblage de la carte, ses portes, marqueurs, transports et interactions doit être codé dans le jeu existant. Les kits donnent les modèles ; ils ne fournissent pas les mécanismes ni la carte originale de Lagos Life.
